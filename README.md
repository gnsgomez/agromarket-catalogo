# AgroMarket - Módulo Catálogo

## Descripción
Este módulo permite a los usuarios visualizar el catálogo de productos agrícolas disponibles en la plataforma AgroMarket. Incluye funcionalidades de búsqueda, filtrado por categorías (frutas, hortalizas, granos) y visualización de detalles de cada producto.
